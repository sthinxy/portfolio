## WHITE SPACE // PORTFOLIO

</div>

Meu portfólio pessoal foi desenvolvido como um espaço digital inspirado na estética de **OMORI**, explorando contrastes entre **WHITE SPACE** e **BLACK SPACE**.

A proposta do site é apresentar minha identidade, meus projetos e minha trajetória na tecnologia através de uma interface minimalista, monocromática e interativa, com elementos visuais inspirados em RPG, telas antigas, silêncio, memória e espaços vazios.

O projeto reúne minhas informações pessoais, habilidades, projetos e formas de contato, mantendo uma experiência visual autoral e imersiva.
