# STHINXY — WHITE SPACE / BLACK SPACE

Portfólio pessoal de **Sthinxy (Ana Beatriz)** inspirado em OMORI.

## Como rodar
Basta abrir `index.html` no navegador, ou hospedar em:
- GitHub Pages
- Netlify (arraste a pasta)
- Vercel
- Qualquer servidor estático

## Atalhos
- **T** — alternar WHITE / BLACK space
- **Espaço** — fechar diálogo

## Estrutura
```
sthinxy-site/
├─ index.html
├─ css/style.css
├─ js/script.js
└─ assets/
   ├─ portrait.png
   └─ portrait-dark.png
```
